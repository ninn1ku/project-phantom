# Журнал архитектурных решений

Формат записи: контекст → решение → причины → последствия → статус.
Статусы: `Proposed` (предложено, ждёт независимой проверки), `Accepted`
(проверено и принято), `Superseded` (заменено другим ADR), `Rejected`.

Решение, влияющее на криптографию, формат протокола или границы модулей,
переходит в `Accepted` только после независимой проверки (см. `AGENT_TASKS.md`).
Менять общую архитектуру без записи здесь нельзя.

## ADR-0001. Размещение проекта в каталоге `phantom/` репозитория NinnikuNPV

- **Дата:** 2026-11-10. **Статус:** Accepted (обратимо).
- **Контекст.** Рабочая сессия имеет доступ к одному репозиторию. Он содержит
  другой проект — панель NinnikuNPV на Python.
- **Решение.** Все файлы PHANTOM лежат в `phantom/`. Каталог не импортирует код
  панели и не меняет её файлы, сборку и CI.
- **Причины.** Единственное доступное место для сохранения работы; контейнер
  сессии эфемерный. Изоляция в одном каталоге позволяет вынести проект в
  отдельный репозиторий без правок содержимого.
- **Последствия.** Когда появится код на Rust, CI панели (`make check`) его не
  проверяет: нужен отдельный workflow с фильтром по `phantom/**` (этап 8).
  Перенос в отдельный репозиторий — по решению владельца.

## ADR-0002. Правила доказательности

- **Дата:** 2026-11-10. **Статус:** Accepted.
- **Контекст.** Задание требует не выдавать предположения за факты и не
  объявлять показатели достигнутыми без измерений.
- **Решение.**
  1. В исследовательских документах утверждения размечаются метками
     **[Факт]**, **[Вывод]**, **[Предположение]**, **[Не проверено]**.
  2. Архитектурное решение может опираться только на **[Факт]** и на явно
     названные **[Вывод]**; опора на **[Предположение]** записывается в ADR
     как риск.
  3. Чужие измерения производительности не переносятся на PHANTOM. Свои
     показатели появляются только после этапа 12 вместе с методикой и сырыми
     данными.
  4. Слова «проверено» и «протестировано» используются только для реально
     выполненных проверок; иначе пишется, что не проверено и почему.
- **Последствия.** Документы длиннее, зато каждое решение прослеживается до
  источника.
