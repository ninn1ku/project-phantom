## Подтверждено

Чтением первичных текстов и исходников (не запуском):

- Требования стандартов, на которых стоит профиль: RFC 8446/9846, 10024, 7250,
  9000, 9001, 9221, 9484 §7.2, 8899.
- Поведение `rustls` 0.23.46 и `quinn-proto` 0.11.19 в местах, от которых
  зависят решения: поддержка raw public keys в `rustls`, порядок отправки
  сертификата клиента, автоматическое обновление ключей, значения по
  умолчанию, поведение размера датаграммы.
- Версии зависимостей и advisories — по crates.io и базе RustSec.
- Ключевые числа исследований фильтрации — по полным текстам трёх публикаций
  USENIX.
- Сведения о клиентах INCY и Happ — по их репозиториям и репозиториям
  Xray-core и sing-box.

## Проверено частично

- Пять замечаний High: перепроверены по документам; статус `Verified`
  возможен только после тестов.
- Переработанный kill switch (ADR-0014): спроектирован после перепроверки,
  сам независимо не перепроверен.
- Спецификация: части проверяли разные исполнители; расхождения между частями
  сведены одним автором (`RECONCILIATION.md`) без независимой проверки.
- Модель угроз 1.0-rc и архитектура v0.3: правки применены, итоговые версии
  повторно не проверялись.
- Отчёты первой волны исследования R1, R2, R3, R5: часть фактов взята из
  поисковой выдачи; при второй волне напрямую сверены только утверждения, на
  которых стоят решения.

## Требует практической проверки

Перечень с запасными вариантами — документ передачи, раздел 11.1. Главное:

1. Raw public keys через `quinn`.
2. Таблица nftables с владельцем из собственного процесса; версии ядра и `nft`.
   Проверяется только на машине с systemd.
3. Схема MTU с `min_mtu = initial_mtu = 1319`.
4. Размер ClientHello и число первых пакетов.
5. Вся производительность и все числовые параметры.
6. Работа сторонних клиентов через MASQUE — на реальных устройствах.
7. Наблюдаемые снаружи характеристики трафика и поведение в реальных сетях.
