# Задачи исполнителей

Исполнители — параллельные потоки с узкой областью ответственности. Lead
Architect ставит задачи, проверяет результаты и отвечает за целостность.
Правило владения: у потока один выходной файл, чужие файлы он не редактирует
и коммитов не делает.

Статус проверки: `не проверено` → `проверено выборочно` → `проверено`.
